# Bin Bypass app (web preview)

Static build of the Bin Bypass app, published from `bin-bypass-diy` with `tools/build_web.sh`.

- `try.html` is the page embedded on binbypass.com: an email sign-up, then the app, comments and feature requests.
- `index.html` is the app itself (collector and CDS / council views).

Data comes live from Supabase with the project's publishable key. Units in Hobart and Brisbane are dummy test data for testing the server and the app at scale.
